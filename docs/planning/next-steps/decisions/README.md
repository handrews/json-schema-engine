# Decision records

A decision is recorded as `NNNN-short-title.md` with status, context,
decision, alternatives, evidence, consequences, compatibility, and follow-up
work. A record is added when an investigation has reviewable evidence, or when
the owner decides on the basis of spec text, probes, or censuses. Each record
is linked from the investigation and roadmap; rejected alternatives stay
discoverable.
